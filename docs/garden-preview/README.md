# 花园板块 · Herbarium 方案预览

> 保留 Kimi 版「12 个圆花圃 + 点选 + 标本详情」的骨架，去掉整张 AI 插画背景和紫色大胶囊，改成一套用 CSS/SVG 画出来的「温室标本室」语言。

## 为什么要换

- Kimi 版的花圃布局（3 列 × 4 行圆盆）很适合手机，也符合花园的节奏；问题在背景是整张 AI 生成的云上庭院，信息密度和 UI 争抢注意力。
- 紫色胶囊、超大圆角、白色浮层与现在项目的经典 / 纸页两套风格都不属于同一套语言。
- 这次不改存档、不改花园数值逻辑，只换视觉层与入口组织。

## 视觉方向：The Herbarium

- **场景全部由代码绘制**：玻璃温室的拱线、石灰岩铺地的细网格、边缘压花枝、纸纹、四角裁切标记。没有位图背景，也就没有 AI 插画味。花盆里额外叠了一层 96px 纸纹颗粒（`grain.png`），让花与土面共用同一张纸的质感。
- **花改成俯视盆栽**：这是这次返工的重点。每株花都画在盆口圆内（SVG `clipPath`），只露出花头、叶片和少量枝梢，不再有长茎伸出盆外。当前花圃有 12 个盆位，种着牡丹、薰衣草、竹、幸运草、仙人掌、鳳尾、荷花、茉莉、樱花、郁金香、玫瑰；空地为种子点。
- **完整 32 种图鉴**：按原项目 `garden.js` 的 `T` 表补齐 29 种原有品种，另加 3 种新花。19 种常见花（玫瑰、向日葵、郁金香、仙人掌、薰衣草、雏菊、樱花、芙蓉、荷花、幸运草、山茶花、百合、牡丹、兰花、枫叶、麦穗、茉莉、鳳尾、竹）与 13 种稀有花（绚樱玫瑰、蓝玫瑰、金向日葵、夜莲、彩虹草、冰玫瑰、星光百合、月光花、水晶兰、凤凰花、嘉兰百合、黑色曼陀罗、星辰花）。图鉴按 COMMON / RARE 分组，未采集的常见花轻微褪色，稀有花仍保留花型和 `RARE` 标签；花圃里种过的 11 种显示拉丁名。每种都有独立花型：雏菊、芙蓉、百合、兰花、枫叶、麦穗、凤凰花、月光花是上一轮新画的；嘉兰百合改成六片狭长、边缘起伏的反卷火焰瓣（金橙尖、绯红根）加一圈超出花瓣的长雄蕊和两缕卷须，黑色曼陀罗是五裂深紫喇叭花，星辰花按勿忘我的五瓣小花做成一簇蓝色花球。
- **花瓣有层次**：参考 orta/plants 和 vector-bloom，每片花瓣独立变长度、宽度、角度，三层到五层叠放；使用径向渐变、暗部投影和纸纹颗粒，避免「一个星形复制十二份」。接入真实数据时按 `garden-plant-name` 映射，未匹配的品种回退通用枝叶。
- **花盆**：92px 石盆，双线盆沿、土面内影、颗粒土、盆底落影；选中时黄铜细环，不动布局。
- **界面**：Times / Mochi Serif 中文衬线 + 6–7px 英文小标；1px 规则线代替卡片；没有紫色胶囊、没有大圆角浮层。
- **色彩**：纸 `#F1EDE3`、墨 `#2B2B24`、鼠尾草 `#77836D`、干玫瑰 `#B37778`、陶土 `#B05F45`、黄铜 `#A98452`。
- **底部换成 3D 工具台**：去掉了原来的文字导航条。现在是一块木质的工具台，放着四件可以拖拽的物件：**水壶**（拖过花盆浇水）、**肥料袋**（施肥）、**种子袋**（拖到空地种植）、**驱虫喷雾**（拖过有虫的花盆驱虫）。拖动时经过的每块地都会生效，松手后给出一句汇总；工具台不再承担页签导航。
- **拖动范围特效**：拖起工具后，跟随指针会出现一圈范围雾：浇水是蓝白水雾，施肥是暖金尘雾，种植是浅绿种子散落，驱虫是灰绿药雾；经过花盆再叠一层小范围水花/雾团。水壶的壶嘴和壶身之间补了黄铜连接套环，不再看起来断成两截。
- **水壶不再是浅灰金属**：原先的米灰金属和纸纹背景几乎同色，看起来像被背景压住。现在改成鼠尾草绿搪瓷壶身 + 黄铜提手、壶嘴套环和洒水头，底部加深、轮廓加粗，放在木质工具台上能立住；拖动时的幽灵壶和托盘里的壶共用同一套颜色。
- **点花盆后的标本弹窗**：底部那排「浇水 / 施肥 / 收获 / 轮盘」文字按钮已移除。花名右边放了一个 82px 的小轮盘，六个图标分别对应浇水、施肥、收获、种植、驱虫、杂交；点图标直接执行，不再出现文字按钮轮盘。
- **顶部页签都能点**：日志 / 图鉴 / 工坊 / 装饰 / 成就 / 年报各有独立的档案页（细线列表、图鉴三列、配方卡、物件价格、成就墙、年报数字），点「花园」或「← 返回花圃」回到花圃，不再是一排摆设。

## 预览

直接打开 `docs/garden-preview/index.html`。带参数的直达状态：

- `?state=sheet`：打开玫瑰的标本抽屉
- `?tab=journal` / `?tab=dex` / `?tab=craft` / `?tab=decor` / `?tab=marks` / `?tab=annual`：直接打开对应档案页
- `preview-sheet.png`：四联总览；`new-flowers.png`：嘉兰百合、黑色曼陀罗、星辰花的放大特写

预览使用本地 `assets/fonts/MochiSerif-Regular.woff2`，不依赖网络字体。

## 接入计划

1. 新增 `src/css/garden-herbarium.css` 与 `src/js/garden-herbarium.js`，只在 `#page-garden.herbarium` 下生效，不改原 `garden.js` 的存档与行为。
2. 先支持 `?garden=herbarium` 预览开关；确认后再设为默认（或做成花园皮肤选项）。
3. 3D 工具只负责「拖到花盆上」这一个交互，落到真实应用时映射到现有 `.garden-tool[data-tool]` 点击；小轮盘的六个图标也走同一套动作，不改存档结构；页签继续复用现有 tab 逻辑。
4. 品种 SVG 映射表放在 CSS/JS 内，新增品种时只补一条；没有 SVG 的品种回退通用枝叶，不会空白。
