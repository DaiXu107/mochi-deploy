# 设置信息架构 · 逻辑表

> 目标：把「设置散、杂、藏在各种地方」变成一套能照着走的逻辑。
> 原则：**按「你想干什么」分组，不按代码模块分组**；总控要保留单功能旋钮。
> 状态：第一版已落地（设置中心 `#page-settings-hub`），原设置页保留为「经典设置」。
> 入口：**桌面第 1 页「设置」图标**（原占卜位）；底部第三个 tab 已改为「一键切换联系人」。

---

## 0. 一句话结论

现在的设置不是「不够多」，而是**没有目录**：同类设置被拆在三个页面（设置 / 聊天设置 / 桌面美化），
同一件事有两条入口且默认值不一致，用户要改「字体」得先知道字号归聊天设置、字体样式归另一个页。

改法不是重排长列表，而是**新增一层设置中心**：

- **首页只回答「我要改哪一类」**（6 类）；
- **高频能力型设置直接在首页改**（字号、回复速度、主动发送、免打扰）；
- **长尾设置给跳转**，跳过去自动高亮目标行（`.sh-hit` 闪一下）；
- **每条都标作用域**（本联系人 / 全局），不用猜；
- **总控 + 单项旋钮并存**：总控一次改一组，单项随时再微调。

- 备份：设置页导出/导入 + 各功能数据页单独清空。

## 2. 六个诊断

1. **分类维度错位**：有的按「页面」分（聊天设置），有的按「对象」分（桌面美化），有的按「实现」分（回复设置），用户无法预判。
2. **同类不同页**：字号、字体、行距分属两页；字体样式和字号是同一件事的两半。
3. **重复入口 + 默认值打架**：同一开关两处可改，读写键相同但默认值不同 → 「我明明开了怎么又关了」。
4. **作用域不可见**：148 个按联系人存的键和 22 个全局键混在一起，界面不标注。
5. **长列表无索引**：设置页 100+ 行只能滚，没有搜索（经典页后来补了 `#set-search-input`，但只在老列表里）。
6. **找不到就以为没有**：散落在功能页里的开关（夜间免打扰、后台保活、应用锁）没有统一出口。

> 然后「有哪些功能」，最后才是「数据」与「安全/关于」。

- 徽章只有两种：紫 `本联系人`、蓝 `全局`；没有徽章＝纯跳转（作用域在目标页里再看）。

## 5. 交互规则

1. **一行一件事**：标题 + 一行小字说明 + 右侧控件；小字必须写「改了会发生什么」。
2. **控件形态固定**：
   - 布尔 → iOS 开关（圆钮位移，不靠颜色判断）；
   - 有界数值 → 步进（− 值 +）；
   - 2–3 个互斥选项 → **轨道 + 白色滑片**（滑片位置＝当前值）；
   - 更多选项 / 在别的页 → 跳转，右侧箭头。
3. **滑动选择**：滑片 `translateX(idx × 100%)`，宽度＝轨道内容宽 / 选项数；拖动中只预览，`change` 才落盘。
4. **搜索**：输入即过滤（匹配标题 + 说明 + 同义词），空结果给提示；清空恢复全部。
5. **跳转反馈**：目标页打开后 80ms 滚到目标并加 `.sh-hit` 高亮 1.4s。
6. **即时生效**：字号改完立刻调用 `applyChatSettings()` / 设置 `--desk-font-scale`，不用重进页面。
7. **不重复写盘**：同值不写（开关/步进先比较再写）。
8. **深色适配**：本页控件全部走 `--sh-*` 局部变量，深色模式有一整套覆盖，不出现白块。

## 7. 兼容性

- 新增页面 `#page-settings-hub`，不删不改原 `#page-setting`；`FULL_PAGES` 不含它（保留底部 tabbar）。
- 入口变更：桌面第 1 页 `.app[data-app="settings"]`（原 `app-divination` 位）；占卜图标移到第 2 页
  `p2` 图标组；底部第三个 tab 无 `data-page`，由 contacts.js 绑定为打开联系人管理弹窗。
  群聊模式开启时占卜仍强制收池，关闭后回第 2 页「此间」之后。
- 所有读写复用现有 `replyCfg()` / `saveReplyCfg()` / `activeStore()` / `xyStore()`，不新增存储键
  （唯一新增的是 `theme-mode` 的直接读写，键名与既有实现一致）。
- 构建：`settings-hub.css` 排在 `setting.css` 之后，`settings-hub.js` 排在 `reply-settings.js` 之后；
  每个 JS 文件仍是独立 IIFE，顶层名不外泄。
- 备份/清理只认 `xy-home-v2:` 前缀，新页不产生新前缀。
