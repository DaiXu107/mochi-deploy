## 二传修改记录

- **2026-10-08**：「TA 状态行」轮换机制调整：①最小冷却从 30 分钟改为 60 分钟，两次状态切换之间至少间隔 1 小时；②到冷却后不再必定切换，改为按「状态轮换概率」掷骰决定是否换一条（未命中＝保持当前、再等下一轮），修复了状态频繁跳动的问题；③回复设置 → 聊天 新增「状态轮换概率」调节项（0~100%，默认 50%，按联系人桌面独立保存，0＝永不自动换、100＝每次到冷却必换）；状态字卡不参与聊天回复的逻辑不变。
- **2026-10-08**：开屏公告移除「下滑到底」门控：进入按钮不再要求把公告滑到底部，只需勾选「我已阅读并同意上方全部说明，确认本人已年满 18 周岁」即可进入；删除了滑到底判定、滚动监听与「请滑到底部后进入」提示等相关代码。
- **2026-10-07**：聊天顶栏新增「TA 状态行」：字卡页（自定义字卡）新增【状态】分类，可分组添加状态字卡（不参与聊天回复）；TA 名字下方以小灰字随机轮换显示（每 30 分钟换一条，按联系人桌面保存）；通话中优先显示「通话中 · 时长」并每秒跳动（仅当前联系人的通话，跨桌面不串台），呼叫/来电也有对应提示。
- **2026-10-07**：「飞行棋」加入群聊：群聊「更多功能」面板放行飞行棋（群聊模式白名单 + 不再切回聊天页），引擎从固定双人升级为 2~4 人通用。群聊内打开时：群人数（含你）≤4 直接开局（全员入座），>4 弹出成员勾选（你 + 最多 3 位被邀请者，默认预选前 3 位）；被邀请成员由 AI 自动掷骰走子，四主题全开（3 人局取三角、2 人局取对角），落点可撞回任一玩家，获胜显示获胜者名字（群局不计单人战绩，单人 1v1 战绩保留）。玩家栏改为按座位动态生成彩色名牌。
- **2026-10-07**：「双人飞行棋」美术与玩法升级：①棋盘换成海洋手绘底图（assets/fc-board.jpg），52 格主航道 / 冲刺区 / 基地停机位全部按底图逐格标定，棋子改为四主题立体徽章（星星 / 海豚 / 小鱼 / 海草）；②新增 3D 骰子（CSS 立方体 + WAAPI 多轴翻滚动画），玩家与对方 AI 投掷同款特效，对方全程自动随机掷骰；③特殊格与底图印刷对齐：回家转弯格改为底图图标格（🐬/↪/🐚/↻），新增「美味的诱惑＝停一回合」「恐怖箱＝随机效果」，冲刺区特殊格（护盾 / 出局等）同步生效；④加固回合状态机：迟到的动画回调不改写回合、关面板重开自动接续被中断的回合。
- **2026-10-07**：聊天页 → 更多功能 → 小游戏 新增「双人飞行棋」。四主题（星星 / 海豚 / 海马 / 仙人掌），掷 6 起飞、落点撞回、同格叠放、特殊格（前进 / 后退 / 再来一次 / 出局 / 碰碰车 / 护盾 / 燃烧卡路里），战绩按联系人桌面本地保存。
- **2026-10-07**：新增「生日分区」——「我的生日」全局 +「梦角生日」按联系人；日历多人生日标记；生日字卡分「我的生日 / 梦角生日」两区；生日当天头像光环与彩带雨，并按概率触发聊天自动生日祝福。
